# 「疑い」の前提の線の見直し（2026-11-12）

前提の線 3,927 本に種類と強さを付けたとき（D-117、relations/needs.yaml）、「前提として要らないように見える」とされた線（疑い）は 310 本あった。
決まり（roadmap.yaml の頭の注）：needs は欠かせない前提だけ。その前提を学んでいないと、あとの単元の中身が理解できないときに限って引く。

## 進め方

- 線ごとに、両端の単元の中身（題名のかっこの中）と、機械で確かめられる手がかり（ほかの前提を通してすでに届くか 54 本、あとの単元の問題がその前提を使うか 3 本、ただ 1 つの前提か 17 本、段の逆 0 本）を並べた。
- 5 組に分け、組ごとに判定の係が「残す・外す・替える（本当の前提は別の単元）・代わり（択一）」を決め、別の係（別のモデル）が疑ってかかって確かめた。
- 替える先は、実在する・あとの単元より段が後でない・輪をつくらない・もう前提にない、を機械で確かめた（問題 0）。
- 反証の係が反対したのは 4 本（残す 3、代わり 1）。取りまとめが読み、4 本とも外すにした：N-022・N-023・N-031 は単元の注に「その前提は使わない」とあり、H-035 → E-232 は関係があるだけで欠かせない前提ではない。
- 外す判定と替える判定は、見本を取りまとめが読んで中身で確かめた。

## 結果

- 外す 216、替える 83（本当の前提へ引きなおす）、残す 11（種類と強さを付けなおす）。疑いの線は 0 になった。
- 前提の線は 4,291 本から 4,075 本になった。単元の深さ（前提の鎖の長さ、2D の地図の横の位置）は 878 単元で変わった（浅くなる 687、深くなる 191）。いちばん深い 38 は変わらない。
- 替えた前提で、あとの単元の考え方の水準が前提より低くなったものが 2 つあり（M-008 ジョルダン標準形 ← M-005 ベクトル空間と線形写像、K-045 暗号の設計 ← R-001 群の定義）、どちらも中身が「定義や原理から体系として組み立てる」なので水準を 3 から 4 に上げた。
- 2D の地図の縦の並び（D-124）を作りなおした。分野と 3D の配置は、疑いの線にもともと 0.3 の小さな重みしか付けていなかったので作りなおさず、次に地図を広げたときにまとめて作りなおす。
