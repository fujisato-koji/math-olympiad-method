# 単元の地図の点検：理解できる順になっているか

2026-11-07 に、独立した点検として係に頼んだもの。指摘の多くを組み直し（D-016）に取り入れた。記号は組み直しの前の形（対応は ../../renamed.yaml）。

- 対象：`roadmap.yaml`（2026-11-07 の組み直しの前。単元 169、段 8、流れ 5。記号は古い形）
- 基準：人がその考えを理解できる順（学年と学習指導要領の順は使わない）
- 施主の追加の前提（途中で受けた）：証明（わけを示すこと）はどの単元にもありうる。段を証明で切らず、「証明の道具」のような段も立てない。これを受けて、証明を書く単元（L1-04、L4-03、L5-01、L6-01、L7-01）を前提にしている指摘は、節 4.3 の「証明の軸」の扱いにまとめた
- やり方：単元の題（plan があれば各日のねらい）から、理解に要る考えを読み取った。それが needs をたどった先（前提の鎖）にあるかは、前提の閉包を計算して 1 件ずつ確かめた。表の「鎖に無い」はすべて計算で確かめてある。閉包は手元の道具で計算した
- 確からしさ
  - 高：題から見て必ず使う考えが、前提の鎖に無い
  - 中：単元の範囲次第で変わる。plan が無い単元（段 2 以降）は題から範囲を推した
  - 低：教え方の流儀に近い

## 0. 全体の所見

1. 式の本線（A3-01 → A3-02 → A5-02〜A5-04 → A6-02）の鎖に、わり算と分数が無い。分数は比と割合（A4-01）を通る単元にしか入っていない。A3-01 か A3-02 に分数を足すと、下流がまとめて直る。
2. 累乗と指数法則（A5-01）は、どの単元の前提にもなっていない。累乗を使う単元は 10 近くある。
3. 不等式の基本（大小の扱い、1 次不等式）を受け持つ単元が無い。不等式、ガウス記号、命題と条件、大きさの議論がこれを使う。
4. 角度（G3-02）の鎖には数の単元が 1 つも無い。図形の流れでは、数や量の前提が全体に薄い。
5. 流れをまたいで、考えの元になる単元が前提に入っていないことが多い。例：一筆書き（C5-03）に偶奇、塗り分けの論法（C5-04）に不変量、約数の個数（N4-02）に積の法則、帰納法（L5-03）に文字が無い。
6. 証明の書き方（L5-01）は 64 単元、わけを言う（L1-04）は 72 単元の前提の鎖に入っている。内容としては要らないのに先に済ませる門になっている（施主の前提とぶつかる。節 4.3）。

### 4.3 施主の前提から見た 3 つの案

#### (1) 証明と説明を、段とは別の軸にする案：妥当。ただし条件がある

根拠：

- Stylianides（S14）は、小学校から証明を扱えるとする。Harel と Sowder（S13）は、演繹の見方を年齢を問わず育てられるとする。ICMI Study 19（S5）は、同じ命題を例、代表の例、文字、公理のどれでも示せると書く。どれも「段ではなく、単元の中の深さ」として扱うことを支える。
- ICMI Study 19（S5）は、形式論理を教えても証明の力に自動的には移らないと書く。「証明の書き方」を単独の単元で教えるより、各単元に溶かす方が筋がよい。

条件：

1. 深さを、大学まで続けられるように 4 つ（と研究の 1 つ）にする。

   | 深さ | 中身 | 枠組みとの対応 |
   |---|---|---|
   | ① 例で見せて口で言う | 具体の例で確かめ、「だから」でつないで言う | Harel と Sowder の経験の型、Tall の身体と知覚の世界 |
   | ② 代表の例で文に書く | 1 つの例を代表にして、どの場合も同じになるわけを書く | ICMI の「代表の例」 |
   | ③ 約束した定義と事実から筋道を立てて書く | その単元で約束した定義と、済んだ単元の事実から書く | Harel と Sowder の変換の型、Freudenthal の局所的な体系化、van Hiele の 3〜4 |
   | ④ 公理から体系として書く | 公理と定義から体系を組む | Harel と Sowder の公理の型、Tall の公理の世界、van Hiele の 5 |
   | ⑤ 定義を選び直す | 証明と反例から定義を作り直す | Lakatos |

2. 深さは段から独立ではない。上限は、その流れで対象をどう見ているかで決まる（van Hiele と Senk）。③ を数、式、数えるの流れで求めるのは、文字を「どの数でも」として使える段（案の 4）から。図形なら合同の単元から。④ は案の 8 から。
3. 必要が出たときに深さを上げる。Harel と Sowder は、形だけ先に求めると「儀式」や「権威」の型が育つとする。深さを上げる日は、例をいくら確かめても足りない問題を置く。
4. 深さごとに、流れごとに初出の単元を 1 つ決め、その日に解いた例を置く。地図には単元ごとに目標の深さ（例 `reason: 2`）を持たせる。道具は「深さ k を求める単元より前に、同じ流れで深さ k の初出がある」ことを確かめる。
5. 他人の証明を読んで穴を見つけることも同じ軸に置く（今の L7-01 の役目）。② から始める。確認の日の判定は、① は保護者が聞く、② と ③ は書いたものを人か AI が読む。
6. 命題の言葉（かつ、または、否定、ならば、すべて、ある、必要十分）は知識なので、L の単元（L5-04 を広げる）として残す。

#### (2) 論理の流れ（L）を「わけを示す方法」に絞る案：妥当

- 方法には前提の順がある（帰納法には文字が要る、鳩の巣の一般形には切り上げが要る）。なので単元として残す意味がある。書き方の単元（L1-04、L4-03、L5-01、L6-01、L7-01）は軸に溶かす。こうすると内容に関係ない門が消え、並行に進められる単元が増える（2-01）。
- 残す方法の例
  - 予想を立てる（L1-01）
  - 条件から絞る（L1-02、L3-04）
  - 仮に置いて確かめる（L2-02、背理法の芽）
  - 場合分け（L3-03）
  - 偶奇（L3-01）
  - 鳩の巣（L3-02 と C6-03）
  - 不変量と単調量（L4-01 と C6-04）
  - 後ろから考える（L4-02）
  - 命題の言葉（L5-04）
  - 背理法（L5-02）
  - 帰納法（L5-03）
  - 極端原理と無限降下（L6-02）
  - 対応させる（C6-07 の考え）
  - 作って示す、評価で示す（C7-02）
  - 少しずつ動かす（C7-05）
- 方法ではないので行き先を決めるもの
  - てんびん（L1-03）：等しさと大小なので、A の方程式の芽にする
  - 数のパズル（L2-01）：N へ
  - 取り合いゲーム（L2-03）：C のゲームへ、または「後ろから考える」の芽にする
  - 集合と写像（L6-03）：方法でなく対象。関係の段の A へ移すか、新しい流れにする
- 注意：L と C に同じ方法が二重にある（鳩の巣 L3-02 と C6-03、不変量 L4-01 と C6-04、ゲーム L2-03・L4-02 と C6-06）。方法は L に寄せ、C は数える対象（グラフ、母関数）に寄せると重なりが消える。

#### (3) 段の境目を、扱う対象の見方の変わり目で切る案：妥当。3 点足すとよい

- 「前の段の手順が次の段の対象になる」（Sfard、Gray と Tall、APOS）の筋に合う。具体物 → 数 → 文字 → 関係 → 構造 → 抽象的な構造 の並びはこれに沿う。活動で切らないので、証明の軸ともぶつからない。
- 足す 1：数と文字の間に「量と比（掛ける、割る、分けるで比べる）」の段を置く。加法から乗法への移りは別の考えで、育つのが遅い（S16）。分数は「割る」という手順の物化（S9）で、「かけると大きくなる」という思い込みが崩れる所（S3）。今の地図で分数、比、面積、約数が段 2〜4 に散っているのは、この段が無いため。
- 足す 2：「わからない数」を「一般の数（わからない数と、どの数でも）」にする。証明（どの n でも）に要るのは「一般の数」の見方で、「変数」は関係の段の入口（S15）。
- 足す 3：構造の扱いを分ける。IMO の大半は構造の段にある（余りの類、多項式、不変量、グラフ、配置）。上位の道具（複素数や重心座標で解く幾何、母関数、多項式法、確率的方法、射影変換）は、問題を別の構造に写して解くことで、Duval のいう表し方の変換にあたる（S17）。分けるなら「構造を移す」を 1 段にし、今の段 7 と 8 のように難しさでは切らない。抽象的な構造（公理）の先は、「構造のあいだ」（写像そのものを対象にする）と「新しい対象をつくる」（研究）に続ける。
- 流れごとのずれ：van Hiele も Harel と Sowder も、見方は内容ごとに違いうるとする。段は全体の目安とし、流れごとに 1 段ずれてよいとする（例：図形は「どの三角形でも」へ早く進める）。

### 4.5 移すときの注意

1. 単元の記号に段の番号が入っている（N3-01）。段を切り直すと記号が変わり、coverage.yaml、units/、画面のデータの参照も変わる。段を単元の属性（`stage:`）にして、記号は流れと通し番号だけにする案がある。どちらにするかは主会話で決める。
2. 段の名前は stages の name に、身につく考え方は about に入る。分や日の配分（minutes、day）は、段の数が変わるので決め直しになる。
3. 大学へ続けるなら、流れ（lanes）を足す。例えば 解析（変化の割合 → 極限と微積分 → ε-δ）、線形（ベクトル → 線形写像 → ベクトル空間）、確率と統計。段の案はそのまま使える。極限は「限りなく続く手順を 1 つの対象にする」ので、関係から構造の段に入る。
