## 確かめの係の指摘から直したこと

- 欠かせない前提でない線を外した：G-055 の C-023、G-056 の T-006 と A-028、S-061 の W-114、Y-022 の P-252、B-187 の W-010、W-122 の E-200。

- 重なりを避けた：K-216 統計的自然言語処理は、隠れマルコフモデルの一般論を K-049 にまかせ、段 9 にして K-049 を前提にした。W-121 写真測量は、SfM とバンドル調整の一般論を K-081 にまかせ、地上基準点、正射変換、数値標高モデル、精度の評価、撮影計画を中心にした。有界な正規作用素のボレル関数計算は D-094 が持ち、D-095 作用素環は連続関数計算までにした。
- 寄せ集めを避けた：候補「計算意味論」は、分布意味論と形式意味論という方法も前提も違う 2 つの伝統の合わせだったので、K-217 分布意味論だけを足した。候補「指数定理と熱核、非有界作用素と作用素環」は 4 つの単元に分けた。候補「測量と写真測量」は 3 つ（基準点、写真、レーザ）に分けた。
