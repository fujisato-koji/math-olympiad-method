# 深い物差しで分野の中の抜けを確かめる（網羅性の再検証、D-117）

- 作成日：2026-11-12
- 目的：みちすじが収める「反復・検証できる知の、いまの形」（D-115）に、分野の中で抜けがないかを、その分野の公開の分類を外の物差しにして確かめる（D-117）。広い物差し（FORD、ISCED-F、ISCO-08）は別のセッションが受け持つ
- 範囲：数学（MSC2020）、統計と確率（MSC2020 の 60・62）、物理（PhySH）、化学（CAS の 80 区分）、計算機（ACM CCS 2012）、医学と生命科学（MeSH）、心理（APA PsycInfo）、地球科学（AGU Index Terms）、経済（JEL）の 9 つ
- 地図（roadmap.yaml）と units/ は変えていない。足りない単元は表に gap と案を書くだけで、足すかは取りまとめで決める（D-117）
- 表：yardsticks/msc2020.yaml、msc2020-stat.yaml、physh.yaml、cas-sections.yaml、acm-ccs.yaml、mesh.yaml、apa-psycinfo.yaml、agu-index.yaml、jel.yaml。書き方と確かめ方は [../yardsticks.md](../yardsticks.md)

## 作り方

1. 分類の原本を公式の出典から取り、記号と名前だけを使った（説明文は写していない）。公式のサイトが機械の取得を断ったもの（ACM、AGU は 403、APA は中身が JavaScript で空）は、Internet Archive にある公式ページの写しから取った
2. 物差しごとに係（Sonnet 5.5、7 人）が、単元の title に並ぶ中身がその項目を受け持つかで、受け持つ（units）・入れない（none）・足りない（gap）を決め、根拠の単元 id を挙げた。名前が似ているかでは決めていない
3. 主会話（Opus 5.5）で、入れないと足りないは全部（313 項目）、受け持つは物差しごとに 2〜3 割（9 つで約 120 項目、受け持つ全体の約 23%）を単元の title と突き合わせて確かめ、直した（直したものは「主会話で直したもの」の節）
4. `python tools/yardstick.py` と `python tools/roadmap.py check` を通した

判断は単元の title に書かれた中身によっている。title にない中身を問題の側で扱っている単元は、受け持たないと数えたことがある。

## 物差しが見つからなかった分野

- **工学**：工学全体の公開の分類で、項目の一覧が自由に読めるものが見つからなかった。Ei Compendex の分類は Elsevier の有料データベースの中にあり、一覧が公開されていない（2026-11-12 に検索した）。Scopus の ASJC は雑誌の分野名の一覧で、工学の中を測るには粗い。工学の抜けは、広い物差し（FORD の 2 工学と技術、ISCED-F の 07）と、ACM（ハードウェア）、CAS（応用化学と化学工学）、PhySH（流体、加速器、原子力）の工学寄りの項目で一部を測った
- **統計**：統計だけの公開の分類で広く使われるものが見つからなかったので、統計の雑誌が使う MSC2020 の 60 と 62 を 3 けたまで下ろした
- **農学と獣医学**：今回は作らなかった。FAO の AGROVOC は語彙集（シソーラス）で分類の樹でなく、CAB の分類は有料
- **社会学、政治学、人類学、言語学、地理学**：社会科学のどこまでを地図に入れるか（D-115）がまだ決まっていないので作らなかった。範囲が決まれば、各学会の分類を物差しにできる。心理と経済の物差しの中で、これらに当たる項目は「判断に迷った項目」に挙げた

## 判断に迷った項目

取りまとめで決めてほしいものを先に、主会話で決めたが弱いものを後に並べた。

**取りまとめで決めてほしいもの**

- **社会学・政治学・人類学・言語学の範囲**：APA 2910 社会構造、2950 結婚と家族、2980 性行動と性的指向、2720 言語学は gap にした。MeSH I01 社会科学は、経済・社会心理・人口で受け持つとしたが、社会学・人類学・政治学の実証の単元はない。JEL Z1（文化経済学・経済社会学・経済人類学）、APA 2930 文化と民族学、2960 政治過程は入れないにした。社会科学を分野ごとに決める（D-115）とき、ここをそろえる必要がある
- **教育の実証を地図に入れるか**：入れる側（足りない）で 5 つの物差しをそろえた。教育の制度・教育課程の設計・教材の作成・学習環境の運営は入れない

## 取りまとめへ

- **先に決めること**：社会学・政治学・人類学・言語学の範囲（D-115 の社会科学を分野ごとに決める）。決まれば、APA の 4 項目、MeSH I01 の受け持つ、JEL Z1 の扱いをそろえ直す
- **足すときに効きの大きい案**：物差しをまたいで多くの項目を受け持つもの。「学習科学と教育の実証」（7 項目）、「高分子の化学と物理」（5）、複雑ネットワークと複雑系（17 項目、3 つほどの案にまとめられる）、「天然物化学」（4）、「産業・組織心理学」（4）、「複素環化合物の化学」（3）、「口腔と歯の科学」（3）、宇宙空間の物理（磁気圏、電離圏、太陽風、宇宙天気で 5）
- **工学**は公開の物差しが見つからなかったので、広い物差しの結果と合わせて抜けを見る
- 判定は単元の title によっている。単元の中身（units/）を作るときに、受け持つとした項目の中心が本当に入っているかを確かめ直す
