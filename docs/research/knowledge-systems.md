# 科学と人文を包含する知の体系の先例（知の体系の調べ）

- 作成日：2026-11-12
- 施主の問い：「科学と人文のようなものを包含する知の体系を構築した例はあるか」
- 目的：みちすじの地図に載せる知の範囲を決めるとき、過去の体系が「検証できる知」と「そうでない知」をどう扱ったかを照らす材料にすること
- 作り方：4 つの切り口（哲学の枠組み、機械で扱う知識基盤と分野分類、百科事典と図書分類、教育課程と人文の定量化）で別々の係が先例を集め（延べ 39 件）、別の係が出典を開いて 1 件ずつ番号順に確かめ、さらに批評役が漏れを挙げた。ディルタイは 2 つの切り口に重ねて出たため、表では 1 行にまとめた（異なる先例は 38 件）
- みちすじの方針（D-115）：反復・検証できる知だけを収録し、人文は入れない。この調べは、その方針の外にある「科学と人文を 1 つに包む体系」がどう作られ、検証の扱いがどうだったかを、方針を変えるためでなく、位置づけるために集めたもの

## 凡例

- **型**：先例を、検証できる知とそうでない知の扱いで 5 つに分けた。どの型に入れるかは、集めた係の「検証できる知の扱い」の記述で決めた。迷うものは近い型に入れ、備考に書いた
  - 型 A：1 つの樹に並べた（検証できるかでは分けない）
  - 型 B：別の妥当性の基準を立てて、同じ見取り図に置いた
  - 型 C：検証できない側を外した、または科学の側へ吸収した
  - 型 D：機械で扱う知識基盤（主張に、出典・文脈・根拠の型を持たせる）
  - 型 E：人文の一部を、検証できる知に近づけた
- **出典の記号**：末尾の「出典」の節の K 番号。確かめ役が実際に開いた URL を載せた
- **確かめ役の直し**：年、作者、構造、扱い方の直しを本文に反映した。確かめ役が確認できなかった細部は外すか「（未確認）」と書いた
- **信頼の目安**：Wikipedia と二次資料を主な出典とする行は、一次資料での照合が済んでいない

## みちすじへの意味

1. **全部を 1 つに包んだ体系は多いが、ほとんどは確かめ方の違いを持たない（型 A）。** ベーコンから Propædia、FORD、ISCED-F まで、分ける根は心の能力・知る対象・学問分野・統計の都合で、「反復・検証できるか」ではない。みちすじの軸（D-115）は、これらと別の軸である。ただし FORD と ISCED-F は、網羅性を確かめる外の物差しには使える。そのときは、人文・芸術の大分野の行に「入れない理由」を書く。
2. **「人文は別の知の体系」という考えに近いのは型 B である。** ディルタイの説明と理解、ヴィンデルバントとリッケルトの法則定立と個性記述、ハーバーマスの 3 つの関心、ハーストの「形式ごとの真理判定の基準」、IB の TOK の「領域ごとの方法論」は、どれも人文に科学とは別の妥当性（理解、価値への関係、意味、整合）を立てた。どれも基準を言葉で述べたが、それを機械で確かめる仕組みは持たない。人文の体系を別に作るなら、まず、その体系での「確かめ方」そのものを定める必要がある。
3. **みちすじ自身は、型 C の統一科学の系譜に近い。** とくに、ノイラートの「下からの体系化」（各科学を相互の予測でつなぐ）と「改訂され続ける百科事典」は、単元の前提の網と、網羅表を作りなおし続けるやり方に重なる。違いは、外した知を「無意味」とせず、別の体系として残すという施主の立場にある。
4. **型 D からは、主張ごとに「根拠の型」を持たせる作りが学べる。** Wikidata は文ごとに参照と順位を持ち、BFO は型の体系と根拠の体系（ECO）を分け、Cyc は主張を文脈（マイクロセオリー）に置く。みちすじでも、単元ごとに「確かめ方の型」（証明、実験、観測、統計、計算）の札を付けられる。そうすると、のちに別の体系（人文）とつなぐときの接点になる。
5. **型 E の、人文の中の測れる部分は、科学の単元として入れられる。** 放射性炭素の年代測定、計量言語学や計量文化学の統計、Seshat の比較のデータは、物理・化学・統計の流れの単元として扱える。解釈の部分は入れない。網羅表では、この境界を単元ごとに書く。
6. **3D の配置から分野を見つけ出す施主の考えには、直接の先例がある。** OpenAlex の Topics は、論文を引用のまとまりでクラスタにし、大規模言語モデルが名前と説明を付けた（型 D の表）。科学全体の地図（science maps）を引用から作る研究もこの系譜にあるが、この調べでは確かめていない。みちすじが違うのは、文献の引用でなく、単元の前提と網羅表の論題の共起という、学ぶ順に結びついた関係を使う点である。
7. **調べた範囲では、科学と人文を 1 つの体系に包み、しかも領域ごとの確かめ方を機械で確かめられる形で持った例は見つからなかった。** 施主の「人文は別の体系」は、型 B の先人の区別と同じ線にある。みちすじは、その科学の側を、型 D の作りで、機械が確かめられる形にする試みとして位置づけられる。
