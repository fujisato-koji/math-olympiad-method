# 広い物差し 3 つの結果（FORD、ISCED-F、ISCO-08）

2026-11-12。D-115（反復・検証できる知のいまの形だけを収録する）と D-117（外の物差しで網羅性を確かめる）にしたがい、公開の分類 3 つを地図の 1,523 単元（194 の問題つき単元を含む）に当てた。表は yardsticks/ford.yaml、yardsticks/isced-f.yaml、yardsticks/isco-08.yaml。書き方は docs/yardsticks.md。地図（roadmap.yaml）と units/ は変えていない。単元が足りないものは表に gap と書いただけで、足すかどうかは取りまとめで決める。

| UNESCO ISCED-F 2013（11 大分野、29 細分野、詳細 80＋2） | 82 | 42 | 34 | 6 | 88% |

「入れない」は D-115 の線引きで、4 種類に分かれる。
- 人文・芸術・宗教・言語：FORD 6.1〜6.5 のすべて、ISCED-F 02 の全部、ISCO の作家・美術家・音楽家・翻訳者・宗教の職など。測れる部分（年代測定、音声の物理、形式言語、論理学、知覚）は、理由の欄に受け持つ単元 id を書いた。
- 規範：法（FORD 5.5、ISCED-F 0421、ISCO の弁護士・裁判官・税関・許認可の公務員など）。法と経済は F-061・F-063、証拠の確率は S-001、目撃証言の記憶は Q-005 が受け持つ。
- 検証できない知：伝統医療・補完医療（ISCED-F 0917、ISCO 2230・3230）。効果を調べる方法は I-001・I-003・I-040 が受け持つ。
- 知の体系でない技能：営業・事務・調理・美容・警備・競技・翻訳通訳の手技など（ISCED-F の職業訓練の分野、ISCO の準専門職の多く）。

出典で食い違いや取れなかったものがある。
- FORD の 6 大分野と 42 分野の表は、指示にあった第 3 章でなく第 2 章（2.6 節）の Table 2.2 にあった。OECD と UNESCO UIS の案内ページは自動取得で 403 や別ページだったため、PDF を直接取った。
- **ISCED-F は、公式の PDF を読めていない。** UIS の PDF の直リンクは 404、UNESDOC は 403、web.archive.org は 429 だった。同じ文書の写し 3 つ（omu.edu.tr、rmutr.ac.th、hec.gov.pk）の Appendix I から符号と名前を取った。前二者は本文が完全に一致し、表紙裏の ISBN・DOI・CC 表記が公式の文書と一致する。写しの個別の URL は取得の記録に残っておらず、表の sources には DOI を書いた。公式の PDF との突き合わせは未了。
- FORD の分野の下の細目（2.7 に石油工学・鉱山工学・船舶工学が入る、3.5 に法医学が入るなど）は Frascati Manual の本文になく、オンラインの付属文書か 2007 年版 FOS にある。今回は取れず、細目に関する判断は係の記憶による。取りまとめの前に確かめる。
- ISCED-F の名前は Appendix I の原文にした。本文の見出しとは 0031（Personal skills と Personal skills and development）、0921（of the elderly）の 2 か所が違う。

## 3. 確かめの方法

- 候補さがしは係（sonnet）に任せた。地図の単元の title 1,523 件を全部読ませ、「名前が似ているか」でなく「title に並ぶ中身がその項目を受け持つか」で決めさせ、根拠の単元 id を挙げさせた。
- 主会話は、none と gap の線引き（D-115）と全体の整合を見た。単元の title を読んで確かめた行は、FORD 5 行（1.2、2.8、5.2、5.3、6.1）、ISCO 18 行（2111、2131、2145、2161、2166、2211、2263、2351、2411、2422、2431、2512、3112、3118、3213、3254、3422、3511）、ISCED-F 9 行（0414、0511、0612、0722、0731、0812、0913、0915、1022）。
- この確かめで直したもの（以下は直したあとの判断）。
  - 教育（FORD 5.3、ISCED-F 0111、ISCO 2351）：同じ内容なのに units と gap に割れていた。教育測定の中心（項目反応理論）は Q-013 にあり、足りないのは授業や介入の効果の実証だけと分かったので、3 つとも gap にそろえた。
  - 政策行政（ISCO 2422）：none だったのを gap に。政策効果の測定は S-042 などにあるが、実証の政治学・行政学（FORD 5.6、ISCED-F 0312 と同じ穴）が足りない。法令の運用と価値判断だけを規範として外した。
  - 航空管制官（ISCO 3154）：none だったのを units に。操縦士（3153）と同じく、気象 P-122、衛星測位 E-166、レーダ E-084 が土台の知を受け持つ。
  - 園芸（ISCED-F 0812）、看護と助産（0913）、治療とリハビリ（0915）：none だったのを units に。ISCO の造園家・看護師・理学療法士が units なのにそろえた。実践の手技は技能で別と理由に書いた。
  - スポーツ（ISCED-F 1014）：none だったのを gap に。運動生理学とトレーニング科学の単元がない（後述 4-8）。
- 機械の確かめ：`python tools/yardstick.py` と `python tools/roadmap.py check`（書き方の誤り、地図にない単元 id、出典がない）。下書きの段階で、理由に書いた単元 id も全部地図にあることを確かめた。

## 5. 大きな抜け

1. **社会科学の実証部分が薄い（4-1〜4-5）。** 3 つの物差しがどれも指す、いちばん大きな抜け。地図の社会科学は心理（Q、21 単元）と経済・金融（F、66 単元）だけで、社会学・政治学・教育学・社会地理・メディアの実証の部分が一つもない。D-115 は「社会科学は実証できる部分を分野ごとに決める」とした。決めた結果は、この 5 分野の実証の部分は入れる範囲に入る、である。取りまとめで最優先。
2. 資源工学（4-6）と医療の専門科・歯学（4-7）が個別の単元を持たない。広い分野は受け持つが、専門の中身が抜けている。
3. スポーツ科学（4-8）。スポーツの数学とデータ（K-065〜K-070）はあるが、人の身体の側（運動生理学）がない。
- 自然科学（FORD 1）、工学の主要部、医学・保健の主要部、農学・獣医学は、3 つの物差しのどれからも大きな抜けは見つからなかった。ISCO の専門職 2 と技術職 3 でも、116 の職が土台の知を単元で受け持ち、足りないのは 4 件だけ。

## 6. 判断に迷った項目

- 法（FORD 5.5）は none（規範）にした。ただし犯罪学の実証（犯罪統計、抑止の効果）の単元がない。FOS 2007 では犯罪学が法の下に入るとされる（付属文書を取れず未確認）。拾うなら 4-1 の社会学の実証の単元に含める。
- メディア・コミュニケーション（FORD 5.8）は gap にしたが、実証が薄い領域なので none の可能性もある。図書館・報道の実務は技能で外した（ISCED-F 0321・0322、ISCO 2622・2642 は none）。
- 残余の項目（FORD 1.7、2.11、3.5、4.5、5.9）は、原文に細目がなく、分野をまたぐ単元を挙げて units にした。none でもよい。
- ISCED-F 0011（基礎課程と資格）は、分野でなく課程の区分と見て none にした。
- ISCED-F 0414・ISCO 2431（マーケティング）は、行動経済学・判断・オンライン実験を挙げて units にしたが、固有の体系は弱い。
- 社会福祉：ISCO 2635（ソーシャルワーク・カウンセリング）はカウンセリングの土台 Q-014 を受け持つので units、ISCO 3412 と ISCED-F 0923 は制度の運用とケースワークなので none。
- 航空：操縦士（ISCO 3153）と管制官（3154）は units（土台の知が大きい）、運輸サービスの訓練（ISCED-F 1041）は運転・操縦の技能なので none。
- ISCO 2162（造園家）は土・水・植物の科学が部分的にあるので units、ISCO 2163（製品・衣服のデザイナー）は芸術・デザインの技能なので none。
- 料理人（ISCO 3434）は none（調理の技能）。土台の食品の科学は V-016・V-003、栄養は I-009・I-052 にあると理由に書いた。
- ISCO の教育（2310、2320、2330、2341、2342、2351、2352、2356、2359）は、土台を「教える教科の知」と「学習の科学」に分けて units にした。言語・社会・芸術の教科は人文として別。2351 だけ gap（4-3）。

## 7. 地図に気づいた点

- 規範寄りの単元がある。I-034（医療と研究の倫理）、F-040（職業倫理と行為基準）、E-198（技術者の倫理と職業の実務）。D-115 が規範を外すのに近いので、取りまとめで扱いを見る（検証できる部分に絞る、外す、など）。
- 理由の欄で「測れる部分」を挙げた人文の項目には、W-010（放射年代測定）、W-031・W-032（同位体地球化学）、Q-008（言語）、L-027・L-028（形式言語）、L-023・L-024・L-043（論理学）、P-022（音の物理）、K-161（言語モデル）が繰り返し出る。人文との接点はこれらの単元に集まっている。
