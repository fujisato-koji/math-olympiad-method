# 問題を転載してよい出典（2026-11-12 に調べた）

施主「算数オリンピックとかいろんな出典が示されているけれど、転載可能な問題ってありますか」。出典ごとに公式の頁（利用規約、著作権の注意、ライセンスの表示）を係が読み、別の係が頁を読みなおして確かめた。取得日はどれも 2026-11-12。法律の助言ではない。

いまの決まり（D-020、D-079）：著作権のある問題は出典と型だけを記録して載せず、同じ型の問題を自作して載せる。著作権の切れた古典 60 問（problems/classics.yaml）だけを、内容から書き直して載せている。リポジトリの内容のライセンスは未定（README）。

## まとめ

- **そのまま載せてよい（パブリックドメイン）**：江戸時代の和算書（『塵劫記』など。国立国会図書館デジタルコレクションの「インターネット公開（保護期間満了）」の画像は申請なしで使える）、Dudeney の原書の英文、Lewis Carroll『A Tangled Tale』の英文。Sam Loyd も推測では満了（1911 年没）だが、頁は読めていない。どれも、現代の訳・注釈・復刻の解説は別の権利なので写さない。
- **条件つきでよい**：Wikibooks（CC BY-SA、継承）、OpenStax・Project Euler・MIT OCW（表示・非営利・継承、CC BY-NC-SA）、公共データ利用規約に従う国の資料（出典の明記、CC BY 互換）。継承（SA）と非営利（NC）は、まだ決めていないリポジトリのライセンスをしばる。
- **許諾が要る**：日本数学オリンピック・ジュニア数学オリンピック（問題使用申請書を FAX）、大学入学共通テスト・センター試験（試験問題利用申請）、全国学力・学習状況調査（無断転載の禁止）、TIMSS（IEA の書面の許諾）、PISA（OECD に照会）。
- **規約が見つからない（載せない）**：算数オリンピック、灘中・灘高の入試、IMO、APMO、EGMO、USAMO（規約の頁が開けない）、エトヴェシュ・キュルシャーク競技会の初期、LibreTexts（頁ごとに違う）、算額（1 件ずつ奉納者の没年で決まる）。
