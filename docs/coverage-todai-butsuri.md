# 網羅表：東京大学大学院理学系研究科物理学専攻（修士課程入試）

この頁は `tools/roadmap.py build` が `coverage-todai-butsuri.yaml` から作ります。手で直さないでください。
東京大学大学院理学系研究科物理学専攻（修士課程入試）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：令和9（2027）年度の修士課程学生募集要項（試験は 2026-08-18）による。数学 1 問、物理学 3 問で、物理学は量子力学・統計力学・古典力学・電磁気学が主な範囲。細目は書かれておらず、過去問のページも取得できなかったため、論題と単元の対応は分野の名称による

論題 5 のうち、単元が受け持つもの 5、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
