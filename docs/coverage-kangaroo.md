# 網羅表：Math Kangaroo

この頁は `tools/roadmap.py build` が `coverage-kangaroo.yaml` から作ります。手で直さないでください。
Math Kangarooに要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：AKSF の学年帯ごとの指針（Math Kangaroo USA が掲載、2021-12）のうち、grades 5-6、7-8、9-10 の 3 本による。grades 1-2、3-4、11-12 は本文を読めなかった。ページは「試験で何が出るかの大まかな指針」とする。日本大会（算数オリンピック委員会）の範囲の文書は公開されていない。論題と単元の対応は名称による

論題 67 のうち、単元が受け持つもの 67、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
