# 2. 構造：組み合わせなしのフロー

第一案（2026-11-07）。地図の中身は [roadmap.yaml](../roadmap.yaml)、段ごとの一覧は [roadmap.md](roadmap.md)（道具が作る）にあります。

## 2.1 表し方

地下鉄の路線図にたとえます（R-25、R-26）。

| 路線図 | メソッド | 数 |
|---|---|---|
| 路線 | 流れ（数、式、数える、図形、論理） | 5 |
| 区間 | 段（入口から IMO まで） | 8 |
| 駅 | 単元 | 137 |
| 線 | 同じ流れの前提（済んでから始める単元） | |
| 札 | ほかの流れや前の段の前提 | |

- 線でつながっていない駅どうしは、並行に進められます。
- 流れをまたぐ前提は、知識として欠かせないものだけにしました（例：面積の前にかけ算）。
- 2 つの流れの考えを合わせて解く単元（例：図の中の三角形を数える）は入れていません。組み合わせは子が見出すものとし、後で別の層として作ります（D-008、R-30）。
- 単元の記号は「流れ・段-番号」です。N1-01 は、数の流れの段 1 の 1 番です。

## 2.3 単元の中

単元は 5〜15 日分です。日には 4 つの種類があります（R-10、R-11、K-5）。

| 日の種類 | 中身 |
|---|---|
| 導入 | 見本（解いた例）を見せてから解く |
| 練習 | 同じ型を少しずつ変えて解く |
| 混ぜる | 前の日や前の単元の型と混ぜて解く（交互練習） |
| 確認 | 8 割できたら、その単元を済にする |

- 段 1 の 15 単元は、1 日ずつのねらいを書きました。
- 段 2 以降は日数だけを決めています。日の並びは既定の形（導入、練習を何日か、混ぜる、確認）です。

## 2.4 問題の書き方

問題は単元ごとに `units/<記号>.yaml` に書きます。

| 欄 | 中身 | 子の画面に出すか |
|---|---|---|
| part | 見本、思い出す、今日、挑戦のどれか | 出す |
| text | 問題の文。段 1 はひらがなの分かち書き | 出す |
| figure | 絵（絵文字）。改行で行を分ける | 出す |
| choices | 選ぶ問題の選択肢 | 出す |
| hints | 3 段のヒント。答えは言わない（R-14） | 1 段ずつ出す |
| answer | 答え | 出さない（保護者の表示だけ） |
| paths | 解答のみちすじ。1 本目が基本、2 本目からは別の道（R-29） | 正しく答えたあとに出す |
| check | 答えを計算で確かめる式（R-12） | 出さない |
| note | よくある間違い、見るところ | 出さない（保護者の表示だけ） |

- `python tools/roadmap.py check` は、すべての `check` の式を計算し、`answer` と合わない問題を誤りとして止めます。
- あわせて、前提の輪、前提の段の逆転、日数の食い違いも確かめます。
- 大会の問題は写さず、問題はすべて自作します（R-22）。
- 今は N1-01（10 までの数）の 5 日分、30 問と見本 2 つを書いています。

## 2.5 画面「みちすじ」

`site/index.html` を開くと使えます。AI は使わない静的な画面なので、子が自分で操作してかまいません（R-15）。

1. **全体の地図**：8 段を縦に並べ、各段に 5 本の路線と駅の点を描きます。「つぎの みちすじ」に、続きの単元と始められる単元を並べます。いくつも並ぶときは、並行の道があるということです。
2. **段の路線図**：流れを横の帯にし、前提を左から右へ線でつなぎます。分かれ道は帯の中で段をずらします。前の段だけが前提の駅は、帯の下の行に横並びでまとめます。
3. **単元**：日を縦の路線に並べ、済んだ日と次の日を示します。
4. **今日**：問題を 1 問ずつ出します。
   - 数を答える問題は数字の板、選ぶ問題はボタンで答えます。
   - 間違えると「もう いちど」と出し、2 回目からヒントを勧めます。
   - 正しく答えると、みちすじが駅の並びとして順に現れます。
   - 保護者の表示を入れると、答え、道筋、見どころ、問題をとばすボタンが出ます。

駅の状態は、次の 4 つです。

| 状態 | 決まり方 |
|---|---|
| 済 | 確認の日に、ヒントなしで一度に 8 割できた |
| いま | 1 日以上やったが、済ではない |
| 次にできる | 前提がすべて済 |
| まだ | それ以外 |

**音**（R-31）：音はすべて画面の中で合成し、音源のファイルは使いません。

- 地図ではペンタトニックの静かな曲が流れます（C、Am、F、G の和音と、近い音へゆっくり歩く旋律）。問題を解いている間は音量と音数を下げます。
- 押したとき、ヒント、正解、間違いに短い音が鳴ります。
- 1 日分を終えると、1 問を 1 音として、たどったみちすじが 1 本のメロディになって鳴ります。ヒントを使った問題の音は柔らかくなります。
- 右上の音符のボタンで消せます。

**記録**（R-19）：進み具合は、その端末のブラウザの中にだけ保存します。「記録」の窓から JSON に書き出し、非公開の math-olympiad-records に置けます。読み込みもできます。
