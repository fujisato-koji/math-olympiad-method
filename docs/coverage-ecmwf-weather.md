# 網羅表：ECMWF の気象・気候の研究者

この頁は `tools/roadmap.py build` が `coverage-ecmwf-weather.yaml` から作ります。手で直さないでください。
世界中の観測と大きなコンピュータ（いまは AI も使う）で、何日も先の天気と地球のようすを予測する。に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 8 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
