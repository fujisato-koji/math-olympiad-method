# 網羅表：ヤマハの楽器と音響の研究者

この頁は `tools/roadmap.py build` が `coverage-yamaha-acoustics.yaml` から作ります。手で直さないでください。
楽器や音響機器の音を、信号処理や AI、新しい素材の研究でよくする。歌声をコンピュータで作る VOCALOID もその成果の一つ。に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 9 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
