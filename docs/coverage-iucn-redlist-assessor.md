# 網羅表：生き物と生態系の絶滅の危険を評価する保全の研究者（IUCN のレッドリスト）

この頁は `tools/roadmap.py build` が `coverage-iucn-redlist-assessor.yaml` から作ります。手で直さないでください。
生き物と生態系の絶滅の危険を評価する保全の研究者（IUCN のレッドリスト）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IUCN の募集 3 件（Red List Programme Officer 7366、ケンブリッジ、2025-08-21 締切。Technical Officer, Biodiversity Assessment 7323、バンコク、2025-07-21 締切、生態系のレッドリスト。GIS Technical Officer 6874、ケンブリッジ、2024-06-23 締切、レッドリストの空間データ）と、評価の職が試験に通ることを求める IUCN の Guidelines for Using the IUCN Red List Categories and Criteria（Version 16、2024 年 3 月）による（2026-11-08 取得）。募集の頁は hrms.iucn.org、指針の PDF は nc.iucnredlist.org から読んだ（iucnredlist.org の頁は 403 で取れなかった）。T-02〜T-08 は指針の章（定義と計算、基準 E、データの質、絶滅の判定、気候変化）から立てた。論題と単元の対応は名称による

論題 17 のうち、単元が受け持つもの 17、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
