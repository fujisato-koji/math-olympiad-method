# 網羅表：国の獣医当局と WOAH・FAO の獣医官（動物の病気と食の安全を守る）

この頁は `tools/roadmap.py build` が `coverage-woah-vet.yaml` から作ります。手で直さないでください。
国の獣医当局と WOAH・FAO の獣医官（動物の病気と食の安全を守る）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：OIE（今の WOAH）の「獣医の卒業時の能力の勧告（Day 1 graduates）」（2012 年 5 月）による（2026-11-08 取得）。基本の能力のうち具体的な 11 項目と、獣医当局で働くのに要る高度な能力 8 項目を論題にした（陸の動物と水の動物の両方）。意思疎通の力は beyond に書いた。WOAH は 2025 年から改訂を始めたが、改訂版は見つからなかった。国際機関（FAO の Animal Health Officer など）の求人は、第三者の転載しか見つからなかったので出典にしていない。論題と単元の対応は名称による

論題 16 のうち、単元が受け持つもの 11、すべての単元に通る軸が受け持つもの 0、入れないもの 5。
