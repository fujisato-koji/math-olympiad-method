# 網羅表：AP Chemistry（College Board）

この頁は `tools/roadmap.py build` が `coverage-ap-chem.yaml` から作ります。手で直さないでください。
AP Chemistry（College Board）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：College Board の AP Chemistry Course and Exam Description（Effective Fall 2024、V.1）による（2026-11-07 取得）。9 Unit、91 Topic。試験は 3 時間 15 分（選択 60 問 90 分と記述 7 問 105 分）、電卓と周期表と公式表を使う。Exclusion Statement で出題しない細目を定める（相図、束一的性質、アレニウスの式の計算など）。有機化学の単元はない。論題と単元の対応は名称による

論題 27 のうち、単元が受け持つもの 27、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
