# 網羅表：食料と農業の研究者（世界食糧賞の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-wfp-laureate.yaml` から作ります。手で直さないでください。
食料と農業の研究者（世界食糧賞の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：世界食糧賞の 1987〜2026 年の受賞理由（worldfoodprize.org の受賞者の一覧と受賞者ごとの頁）による（2026-11-08 取得）。本体の頁はボット対策で中身が返らなかったので、Internet Archive の写し（2024〜2026 年）で読んだ。研究と技術の業績で受けた回だけを論題にし、政策・援助・組織や事業づくりで受けた回（1988、1989、1993、1994、1998、2001、2003、2008、2010、2011、2015、2017、2018、2019、2023）は除いた。論題と単元の対応は名称による

論題 25 のうち、単元が受け持つもの 25、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
