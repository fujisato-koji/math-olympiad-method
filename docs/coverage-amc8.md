# 網羅表：AMC 8（MAA）

この頁は `tools/roadmap.py build` が `coverage-amc8.yaml` から作ります。手で直さないでください。
AMC 8（MAA）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：MAA の AMC のページの topics の列挙による（検索エンジンの抜粋で取得し、文言は原文との照合が要る）。「これに限らない」の注つき。8 年生以下、25 問 40 分の選択式。後半の問題は初歩の代数（一次関数か二次関数、座標幾何）に触れることがある。論題と単元の対応は名称による
