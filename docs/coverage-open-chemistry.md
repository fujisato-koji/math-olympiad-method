# 網羅表：化学の大きな未解決問題（生命のキラリティ、人工光合成、周期表の果てなど）

この頁は `tools/roadmap.py build` が `coverage-open-chemistry.yaml` から作ります。手で直さないでください。
化学の大きな未解決問題（生命のキラリティ、人工光合成、周期表の果てなど）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：上海交通大学と Science 誌の "125 Questions: Exploration and Discovery"（2021）の化学の問い（周期表は完成するか、生命はなぜキラリティを必要とするか）と、Science 誌の "What Don't We Know?"（2005、自己組織化）。窒素固定、人工光合成、結晶構造の予測、交換相関汎関数は、それぞれの分野の一次資料（Nature の手順の論文、CCDC のブラインドテスト、総説）で未解決と確かめた（2026-11-08）。

論題 7 のうち、単元が受け持つもの 7、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
