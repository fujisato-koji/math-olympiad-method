# 最難関（決勝級）の物差し

`problems/sansu-olympic.yaml` の決勝の記録から 5 つの型を選び、`key` の工夫が何段あるかを数えた。最難関は、このどれかと同じくらいの工夫を要するものにする。

| 型 | 記録 | key の工夫 | 段数 |
|---|---|---|---:|
| 偶奇と上限で候補を絞る | SO-2024-1 | 偶奇で 2 の位置を決める → 最大の素数で和の上限を作る → 場合分けして全部確かめる | 3 |
| 回転の合同で長さ・面積を戻す | SOJ-2024-1 | 回転で辺と角を対応させる → 台形の上底と下底の和を出す → 高さを戻す | 3 |
| 共有辺の二重計上を整理する | SOJ-2025-1 | 共有辺を二重に数えない → 黒い部分の周を先に出す → 青い部分の合計を出す | 3 |
| 隣接状態を漸化式にする | SO-2024-2 | 隣り合う 2 桁を状態にする → 次に付け加えるブロックを数える → 漸化式で伸ばす | 3 |
| 相手の手と合わせて一定量にする | SOJ-2024-2 | 相手の手を見る → 合わせて一定量になるように返す → 最後まで石が足りることを確かめる | 3 |

## 最低条件

1. 上の型のどれかと同程度で、**工夫の段が 3 以上**ある。
2. 公式に当てはめるだけでなく、言いかえ・不変量・対称性・場合分けの工夫が 1 つ以上ある。
3. `paths` が 4 段以上で、2 本以上ある。2 本は言いかえでなく、考え方が違う。
4. その単元と前提（`uses`）で習ったことだけを使う（D-068）。
5. 数で答える問題は `check` があり、全場合を調べた方法を `note` に書く。
6. 文と図が一致し、その学年が読める言葉で書く。

評価役は、この表と問題を並べ、上の 6 つを 1 問ずつ判定する。
