# 網羅表：IMF（国際通貨基金）のエコノミスト（Economist Program）

この頁は `tools/roadmap.py build` が `coverage-imf-economist.yaml` から作ります。手で直さないでください。
IMF（国際通貨基金）のエコノミスト（Economist Program）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IMF の Economist Program の公式の頁（応募の条件と仕事の分野：国の監視と支援プログラム、財政・金融・金融部門・債務・対外部門）、Experienced Economists の頁（マクロ経済学、金融経済学、財政、国際貿易、計量経済学）、2018 年の選考の頁（面接は金融政策、財政、国際収支、金融部門の問題）、2027 年の募集の転載による。論題は分野の名前から立て、単元は名称で当てた

論題 16 のうち、単元が受け持つもの 15、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
