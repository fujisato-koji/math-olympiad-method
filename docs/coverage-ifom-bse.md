# 網羅表：医学の基礎の国際試験（NBME の IFOM 基礎医学試験）

この頁は `tools/roadmap.py build` が `coverage-ifom-bse.yaml` から作ります。手で直さないでください。
医学の基礎の国際試験（NBME の IFOM 基礎医学試験）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：NBME の IFOM Basic Science Exam Blueprint（総論 28〜30% と 10 の器官系の配分）と、NBME の IFOM の頁（https://www.nbme.org/institutions/assess-learn/international-foundations-medicine/）による（2026-11-08 取得）。器官系の論題は、正常の構造と働き、異常の過程、治療の原則をまとめて 1 論題にした。神経系は B の神経の単元が受け持つ。論題と単元の対応は名称による

論題 25 のうち、単元が受け持つもの 25、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
