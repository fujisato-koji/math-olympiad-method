# 網羅表：ЕГЭ（数学 профильный уровень）

この頁は `tools/roadmap.py build` が `coverage-ege-profile.yaml` から作ります。手で直さないでください。
ЕГЭ（数学 профильный уровень）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：ФИПИ の 2027 年の кодификатор と спецификация による。これらは確定版ではなく案（ПРОЕКТ、2026 年 8〜9 月付）。論題は кодификатор の内容の要素と要件から取った。論題と単元の対応は名称による

論題 32 のうち、単元が受け持つもの 31、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
