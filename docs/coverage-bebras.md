# 網羅表：Bebras（International Challenge on Informatics and Computational Thinking）

この頁は `tools/roadmap.py build` が `coverage-bebras.yaml` から作ります。手で直さないでください。
Bebras（International Challenge on Informatics and Computational Thinking）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：年齢帯と問題の数は、米国の主催者 USA Bebras Computing Challenge の頁による（Kits 6〜8 歳、Castors 8〜10 歳、Benjamins 10〜12 歳、Cadets 12〜14 歳、Juniors 14〜16 歳、Seniors 16〜18 歳、45 分）。国際の bebras.org は JavaScript だけの頁で中身を読めなかった。論題の区分は、Bebras の創始者らが提案した 2 次元の分類（内容 5 区分と計算論的思考の技能 5 つ、Informatica 2017）による。各国は国際の問題の集まりから選ぶので、国により年齢帯と問題が少し違う。論題と単元の対応は名称による

論題 13 のうち、単元が受け持つもの 12、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
