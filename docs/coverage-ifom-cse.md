# 網羅表：医学の臨床の国際試験（NBME の IFOM 臨床医学試験）

この頁は `tools/roadmap.py build` が `coverage-ifom-cse.yaml` から作ります。手で直さないでください。
医学の臨床の国際試験（NBME の IFOM 臨床医学試験）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：NBME の IFOM Clinical Science Exam Blueprint（総論 5〜7% と 14 の病気の群の配分）と、NBME の IFOM の頁（https://www.nbme.org/institutions/assess-learn/international-foundations-medicine/）による（2026-11-08 取得）。病気の群ごとの「健康の維持、病気のしくみ、診断、管理の原則」はまとめて 1 論題にし、診断と管理の考え方を別の論題にした。論題と単元の対応は名称による

論題 18 のうち、単元が受け持つもの 18、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
