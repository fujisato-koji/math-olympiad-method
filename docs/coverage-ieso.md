# 網羅表：国際地球科学オリンピック（IESO）

この頁は `tools/roadmap.py build` が `coverage-ieso.yaml` から作ります。手で直さないでください。
国際地球科学オリンピック（IESO）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：国際地球科学教育機構（IGEO）の IESO の Goals, objectives and syllabus（委員長 Nir Orion）による。公式の ieso-info.org はいまは別のサイトになっていて、IGEO の igeoscied.org は TLS の接続ができなかったので、Internet Archive の写し（2022-09-26 の公式の頁）で取った。シラバスは地球システムの考え方（地圏・水圏・気圏と惑星系、それぞれの主な考えと技能）でまとめ、細目の少ない原則の文書である。参加資格は IESO Statutes 第 4 版（2016、同じく写し）による。論題は 4 つの系の主な考えと技能の項目から立てた。論題と単元の対応は名称による

論題 18 のうち、単元が受け持つもの 17、すべての単元に通る軸が受け持つもの 1、入れないもの 0。
