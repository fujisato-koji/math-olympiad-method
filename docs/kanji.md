# 漢字の範囲と点検

- 教育漢字（学年別）
  - 出典：kanjiapi.dev の学年別漢字（grade-1〜grade-6）
  - URL：https://kanjiapi.dev/v1/kanji/grade-1 （grade-2 以下も同じ形）
  - 取得日：2026-11-11
  - 保存：`tools/kanji-grades.json`（第 1〜6 学年の教育漢字 1,006 字）
- 常用漢字
  - 出典：kanjiapi.dev の常用漢字の一覧（joyo）
  - URL：https://kanjiapi.dev/v1/kanji/joyo
  - 取得日：2026-11-20
  - 保存：`tools/kanji-joyo.json`（2,140 字。常用漢字表の 2,136 字に、異体の字が少し入る。教育漢字はすべて含む）
- 元のデータとライセンス：kanjiapi.dev の字の一覧は、EDRDG の KANJIDIC2 から作られている（kanjiapi.dev の README、https://github.com/onlyskin/kanjiapi.dev 、2026-11-20 に確かめた）。KANJIDIC2 は EDRDG のライセンス（Creative Commons 表示-継承 4.0）。ここでは字の一覧だけを使う。

## 水準ごとの字の範囲（D-220、docs/thinking-levels.md の第 5 節）

| 水準 | 使える字 |
|---|---|
| 1 | 小 1 の字（80 字） |
| 2 | 小 2 までの字（240 字） |
| 3 | 小 4 までの字（640 字） |
| 4 | 教育漢字（小 6 まで、1,006 字） |
| 5 | 常用漢字（表外字は用語集の語だけ） |
| 6、7 | 決まりなし |

`python tools/roadmap.py check` は、水準 1〜5 の単元の問題文・ヒント・選択肢・説明・道筋・注を、その水準の字の範囲と比べ、上回る漢字が残る単元を警告で出します（誤りにはしません）。

例外として、`glossary.yaml` の `term` に使う漢字と、単元の頭注（2 行目以降の `#` 行）に書かれた漢字は許します。頭注はその単元で使うことばの説明を含むためです。題（1 行目）は例外にしません。「必勝法」の「必」のような、子に見せる文ではない字まで許さないためです。

警告は、その水準の読み手が読めるかを人が見直す手がかりです。機械的に消すのではなく、ことばを選び直すか、その単元の用語として頭注に書くかで直します。先に進んだ小さい子が上の水準の単元を読むときは、画面のふりがなで助けます（docs/thinking-levels.md の 4.3）。
