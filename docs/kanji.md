# 漢字の学年と点検

- 出典：kanjiapi.dev の学年別漢字（grade-1〜grade-6）
- URL：https://kanjiapi.dev/v1/kanji/grade-1 （grade-2 以下も同じ形）
- 取得日：2026-11-11
- 保存：`tools/kanji-grades.json`（第 1〜6 学年の教育漢字 1,006 字）

`python tools/roadmap.py check` は、段 1〜6 の単元の問題文・ヒント・選択肢・説明・道筋・注を、その段の学年までの教育漢字と比べ、上回る漢字が残る単元を警告で出します（誤りにはしません）。段 7 以上は対象外です。

例外として、`glossary.yaml` の `term` に使う漢字と、単元の頭注（2 行目以降の `#` 行）に書かれた漢字は許します。頭注はその単元で使うことばの説明を含むためです。題（1 行目）は例外にしません。「必勝法」の「必」のような、子に見せる文ではない字まで許さないためです。

警告は、その段の子が読めるかを人が見直す手がかりです。機械的に消すのではなく、ことばを選び直すか、その単元の用語として頭注に書くかで直します。2026-11-11 の時点で 190 単元に警告が残っています。
