# 網羅表：GRE Physics Test（ETS）

この頁は `tools/roadmap.py build` が `coverage-gre-physics.yaml` から作ります。手で直さないでください。
GRE Physics Test（ETS）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：ETS の内容の頁と練習帳による。約 70 問で、大半は学部の最初の 3 年の物理で解ける。出題比率は古典力学 20%、電磁気学 18%、光学と波動 8%、熱力学と統計力学 10%、量子力学 13%、原子物理 10%、特殊相対論 6%、実験の方法 6%、専門の話題 9%。各分野は「such as」で例示されるだけなので、論題と単元の対応は名称による。数学の方法は ETS が挙げる多変数の微積分、ベクトル解析、フーリエ級数、偏微分方程式、行列と行列式、複素関数

論題 13 のうち、単元が受け持つもの 13、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
