# 網羅表：経済学の大きな未解決問題（株式プレミアムの謎、国の豊かさの違い、生産性の鈍化など）

この頁は `tools/roadmap.py build` が `coverage-open-economics.yaml` から作ります。手で直さないでください。
経済学の大きな未解決問題（株式プレミアムの謎、国の豊かさの違い、生産性の鈍化など）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：Mehra と Prescott（1985）の株式プレミアムの謎、Obstfeld と Rogoff（2000）の国際マクロ経済学の 6 つの謎、Meese と Rogoff（1983）、2024 年のノーベル経済学賞の発表、Syverson（2017）、Bernanke と Blanchard（2025）。経済学には学会の公式の未解決問題の一覧がないので、謎として名づけられ長く引用されているものを選んだ。

論題 6 のうち、単元が受け持つもの 6、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
