# 網羅表：Math Kangaroo（7・8 年生）

この頁は `tools/roadmap.py build` が `coverage-kangaroo-7-8.yaml` から作ります。手で直さないでください。
Math Kangaroo（7・8 年生）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：AKSF の指針 grades 7 and 8 の箇条による（いまの coverage-kangaroo.yaml の 7-8 年の論題を引き継いだ）。論題と単元の対応は名称による

論題 22 のうち、単元が受け持つもの 22、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
