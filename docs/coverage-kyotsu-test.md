# 網羅表：大学入学共通テスト（数学）

この頁は `tools/roadmap.py build` が `coverage-kyotsu-test.yaml` から作ります。手で直さないでください。
大学入学共通テスト（数学）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：令和 9 年度試験の『数学Ⅰ，数学Ａ』『数学Ⅰ』『数学Ⅱ，数学Ｂ，数学Ｃ』。大学入試センターの文書は科目と項目の単位までなので、細目は学習指導要領から取った。数学Ⅲ、数学Ａの整数、数学Ｃの行列は範囲外。論題と単元の対応は名称による

論題 47 のうち、単元が受け持つもの 47、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
