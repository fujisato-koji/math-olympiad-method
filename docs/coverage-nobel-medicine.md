# 網羅表：生命科学の研究者（ノーベル生理学・医学賞の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-nobel-medicine.yaml` から作ります。手で直さないでください。
生命科学の研究者（ノーベル生理学・医学賞の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：2012 年と 2016〜2026 年のノーベル生理学・医学賞の授賞の分野（nobelprize.org の授賞の理由）と、医学の入口として AAMC の MCAT の範囲（Foundational Concepts 1〜10）による（2026-11-07 取得）。MCAT は医学部の入口で、博士課程の入口ではない。論題と単元の対応は名称による

論題 32 のうち、単元が受け持つもの 31、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
