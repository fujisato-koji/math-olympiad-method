# 網羅表：中国の普通高等学校招生全国統一考試（高考、数学）

この頁は `tools/roadmap.py build` が `coverage-gaokao.yaml` から作ります。手で直さないでください。
中国の普通高等学校招生全国統一考試（高考、数学）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：全国卷の数学。範囲は普通高中数学課程標準（2017 年版 2020 年修訂）の必修課程と選択性必修課程。選学の印が付いた項目（複素数の三角表示、数学的帰納法、ベイズの公式）は考試の要求としないので含めない。積分の項目はない。論題と単元の対応は名称による

論題 41 のうち、単元が受け持つもの 41、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
