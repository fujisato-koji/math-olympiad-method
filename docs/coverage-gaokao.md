# 網羅表：中国の普通高等学校招生全国統一考試（高考、数学と理科）

この頁は `tools/roadmap.py build` が `coverage-gaokao.yaml` から作ります。手で直さないでください。
中国の普通高等学校招生全国統一考試（高考、数学と理科）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：数学は全国卷で、範囲は普通高中数学課程標準（2017 年版 2020 年修訂）の必修課程と選択性必修課程。選学の印が付いた項目（複素数の三角表示、数学的帰納法、ベイズの公式）は考試の要求としないので含めない。積分の項目はない。選んで受ける科目の組み方は省ごとの実施方案による。ここでは多くの省が使う 3+1+2 の型（例：広東省の実施方案）で表す。首選科目は物理か歴史から 1 つ、再選科目は思想政治・地理・化学・生物から 2 つで、考試の内容は国の課程標準による。表には物理・化学・生物と、地理の自然地理（地理 1 と選択性必修 1）を載せた。論題は各科の課程標準の必修と選択性必修の内容要求を、番号ごとにまとめた。選ぶ科目は道のりに入れず、首選の物理は 20 論題、再選は単元のある論題の少ない 2 科目分（35）まで数える。論題と単元の対応は名称による

論題 120 のうち、単元が受け持つもの 120、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
