# 網羅表：ITER の核融合の研究者

この頁は `tools/roadmap.py build` が `coverage-iter-fusion.yaml` から作ります。手で直さないでください。
太陽や星と同じ核融合でエネルギーを取り出すため、世界最大のトカマクを動かす準備をする。に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 9 のうち、単元が受け持つもの 7、すべての単元に通る軸が受け持つもの 0、入れないもの 2。
