# 網羅表：宇宙を観る天文学者（James Webb 宇宙望遠鏡、Event Horizon Telescope）

この頁は `tools/roadmap.py build` が `coverage-sky-astronomer.yaml` から作ります。手で直さないでください。
宇宙を観る天文学者（James Webb 宇宙望遠鏡、Event Horizon Telescope）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 28 のうち、単元が受け持つもの 26、すべての単元に通る軸が受け持つもの 0、入れないもの 2。
