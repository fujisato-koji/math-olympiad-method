# 網羅表：mRNA ワクチンをつくる研究者（Moderna）

この頁は `tools/roadmap.py build` が `coverage-mrna-vaccine.yaml` から作ります。手で直さないでください。
mRNA ワクチンをつくる研究者（Moderna）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：2023 年ノーベル生理学・医学賞（mRNA の塩基の修飾）の発表、Moderna の研究職の募集 3 件（2026 年）、BioNTech の 2020-03-16 の発表による（2026-11-07 取得）。T-08〜T-10 は募集の職の分野（トランスレーショナル免疫学、タンパク質設計、分析化学）による。論題と単元の対応は名称による

論題 11 のうち、単元が受け持つもの 11、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
