# 網羅表：生態学の大きな未解決問題（種の多様性、共存、生態系の転換点など）

この頁は `tools/roadmap.py build` が `coverage-open-ecology.yaml` から作ります。手で直さないでください。
生態学の大きな未解決問題（種の多様性、共存、生態系の転換点など）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：英国生態学会の会員などが選んだ "Identification of 100 fundamental ecological questions"（Sutherland ほか、J. Ecology 2013）と、Science 誌の "What Don't We Know?"（2005、種の多様性を決めるもの、協力行動の進化）。地球の種の数は Mora ほか（PLoS Biology 2011）による。

論題 7 のうち、単元が受け持つもの 7、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
