# 網羅表：A level Physics（AQA 7408）

この頁は `tools/roadmap.py build` が `coverage-alevel-phys.yaml` から作ります。手で直さないでください。
A level Physics（AQA 7408）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：AQA AS and A-level Physics Specification（7407/7408、Version 1.4、July 2026）による（2026-11-07 取得）。3.1〜3.8 が必修で、3.9〜3.13（天体物理、医用物理、工学物理、物理学の転換点、電子工学）から 1 つを選ぶ。筆記 3 回（各 2 時間。Paper 3 は実験とデータ解析 45 点と選んだ分野 35 点）。論題と単元の対応は名称による

論題 21 のうち、単元が受け持つもの 21、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
