# 網羅表：地震と火山の研究者（米国地質調査所 USGS）

この頁は `tools/roadmap.py build` が `coverage-usgs-quake-volcano.yaml` から作ります。手で直さないでください。
地震と火山の研究者（米国地質調査所 USGS）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：USGS の Mendenhall Research Fellowship の研究の機会 3 件（23-19 地震の連なりとその変わり方、23-25 世界の地震の素早い自動の速報、23-26 アラスカの火山の揮発性成分。どれも 2024-11-01 締切。USGS の頁と USAJOBS の募集 810429100・810415700）と、ハワイ火山観測所の Geophysicist（USAJOBS 824043400、2024-12-16〜12-20）による（2026-11-08 取得）。Mendenhall は博士の直後の 2 年の研究職。T-01〜T-04 は 23-19、T-05〜T-07 は 23-25、T-08〜T-10 は 23-26、T-11〜T-13 はハワイの職による。論題と単元の対応は名称による

論題 14 のうち、単元が受け持つもの 14、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
