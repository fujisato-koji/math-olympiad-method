# 網羅表：合成生物学とバイオインフォマティクスの研究者（EMBL、EMBL-EBI）

この頁は `tools/roadmap.py build` が `coverage-embl-synbio-bioinfo.yaml` から作ります。手で直さないでください。
合成生物学とバイオインフォマティクスの研究者（EMBL、EMBL-EBI）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：EMBL Heidelberg の Steinmetz 研究室の Postdoctoral Fellow – Synthetic Biology Design and Evolution（HD01874、2020-12-14 掲載、2021-01-07 締切。研究室の募集の頁の Internet Archive の写し 2022-03-02 で読んだ）と、EMBL-EBI の Ensembl Microbes Bioinformatician（JR4343、2026-10-28 掲載。本文は EMBL の採用の頁（Workday）が読む公開の求人データから読んだ）による（2026-11-08 取得）。EMBL のいまの募集に合成生物学の研究職がないので、合成生物学は過去の募集を使った。T-01〜T-08 は合成生物学の職、T-11〜T-18 は Ensembl の職による。論題と単元の対応は名称による

論題 18 のうち、単元が受け持つもの 18、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
