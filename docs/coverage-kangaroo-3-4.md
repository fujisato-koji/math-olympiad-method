# 網羅表：Math Kangaroo（3・4 年生）

この頁は `tools/roadmap.py build` が `coverage-kangaroo-3-4.yaml` から作ります。手で直さないでください。
Math Kangaroo（3・4 年生）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：AKSF の指針 grades 3 and 4（画像の PDF を読み取った）の箇条による。指針は短いので、オーストリアの 2025 年の Écolier（3・4 年）の問題に出た型（空間の見方、折り紙と結び目、カレンダー、てんびん、文章題、並びのきまり）を、問題文は写さずに論題として足した（IN007）。論題と単元の対応は名称による

論題 17 のうち、単元が受け持つもの 17、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
