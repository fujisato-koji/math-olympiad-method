# 網羅表：国際情報オリンピック（IOI）

この頁は `tools/roadmap.py build` が `coverage-ioi.yaml` から作ります。手で直さないでください。
国際情報オリンピック（IOI）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IOI の国際科学委員会による IOI Syllabus（IOI 2025 の公式版、2024-02 改訂）の「含む」（無制限、定義を添える、問題文には出さない）に分類された論題による（2026-11-08 取得）。「焦点の外」と「除く」（線形代数、微積分、計算可能性、NP 困難の証明など）は論題にしない。資格は IOI Regulations（2024）による。論題は節（§5 数学、§6 計算機科学、§7 ソフトウェア工学）の細目をまとめて立てた。論題と単元の対応は名称による

論題 21 のうち、単元が受け持つもの 21、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
