# 網羅表：化学者（ノーベル化学賞の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-nobel-chemistry.yaml` から作ります。手で直さないでください。
化学者（ノーベル化学賞の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：2016〜2026 年のノーベル化学賞の授賞の分野（nobelprize.org、2026-11-07 取得）と、大学院の入口の基礎として欧州の化学教育の中核の枠組み（ECTN、2026 年 5 月版）と英国の化学の学位の基準（QAA、2022）による。どちらも学部の中核の基準で、博士課程の入口より一段下の基礎にあたる。論題と単元の対応は名称による

論題 31 のうち、単元が受け持つもの 31、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
