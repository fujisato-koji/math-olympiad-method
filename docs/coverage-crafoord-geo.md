# 網羅表：地球科学者（クラフォード賞の地球科学部門の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-crafoord-geo.yaml` から作ります。手で直さないでください。
地球科学者（クラフォード賞の地球科学部門の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：1983〜2026 年のクラフォード賞の地球科学部門の授賞の理由（13 回）と、固体地球と古気候を補う 2000〜2023 年のヴェトレセン賞（表に V を付けた）による。大学院の入口は、カリフォルニア工科大学 地球・環境部門（地質・惑星科学）の大学院の入門科目（Ge 101〜163、2026-27 年の科目一覧）による（2026-11-07 取得）。クラフォード賞は天文学と数学、多発性関節炎、地球科学、生物科学の順に回り、地球科学はおよそ 4 年に 1 回。大気と海洋の論題は物理の流れ（気象と気候）の単元に、固体地球と地球化学と古気候は新しい地球科学の流れ W に当てた。論題と単元の対応は名称による

論題 20 のうち、単元が受け持つもの 20、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
