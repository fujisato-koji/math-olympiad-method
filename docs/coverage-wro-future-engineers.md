# 網羅表：World Robot Olympiad（Future Engineers、自動運転車）

この頁は `tools/roadmap.py build` が `coverage-wro-future-engineers.yaml` から作ります。手で直さないでください。
World Robot Olympiad（Future Engineers、自動運転車）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：WRO Association の 2026 Future Engineers Self-Driving Cars General Rules（焦点の領域と 2 つの課題）と Documentation Rubric（評価の 5 つの基準）による（2026-11-08 取得）。課題は毎年 2〜3 割変わり、4〜5 年で全部変わる。論題は焦点の領域と評価の基準から立てた。論題と単元の対応は名称による

論題 8 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
