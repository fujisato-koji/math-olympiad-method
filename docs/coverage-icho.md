# 網羅表：国際化学オリンピック（IChO）

この頁は `tools/roadmap.py build` が `coverage-icho.yaml` から作ります。手で直さないでください。
国際化学オリンピック（IChO）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IChO 規則（Regulations of the IChO、2023-08-01 施行）の付属 C の syllabus による（第 58 回の開催国のサイトの PDF、2026-11-07 取得）。現行の付属 C は「全員が知るべき知識と実験技能」と「上級分野の例」の 2 層で、2004 年版のレベル 1〜3 の区分はない（T-30〜T-40 が上級分野の例）。開催国は付属 C の外から理論 6、実験 3 分野まで出せ、1 月の準備問題で示す。T-41〜T-49 は第 58 回（2026、ウズベキスタン）の準備問題が示した上級分野。論題と単元の対応は名称による

論題 49 のうち、単元が受け持つもの 49、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
