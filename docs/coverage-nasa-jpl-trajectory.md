# 網羅表：NASA JPL の軌道設計者

この頁は `tools/roadmap.py build` が `coverage-nasa-jpl-trajectory.yaml` から作ります。手で直さないでください。
宇宙船が目的地に着くまでの道すじを前もって計算して決め、飛んでいる間に本当の位置を測り、ずれたら直す。に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 7 のうち、単元が受け持つもの 6、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
