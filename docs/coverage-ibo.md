# 網羅表：国際生物学オリンピック（IBO）

この頁は `tools/roadmap.py build` が `coverage-ibo.yaml` から作ります。手で直さないでください。
国際生物学オリンピック（IBO）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IBO Operational Guidelines v7.0（2026-09-05）の理論の配分（§3.7.3）と実験の技能の一覧（付録 2）による（2026-11-07 取得）。配分は細胞生物学 20%、植物の解剖と生理 15%、動物の解剖と生理 25%、行動学 5%、遺伝と進化 20%、生態学 10%、生物系統学 5%。IBO は論題の syllabus は今はないとするため、分野の細目は旧版の IBO Guide（第 25.1 版、2013）の付録 I（第三者のサイトの写し）による。付録 2 は一部が古く改訂中と自ら注記する。知識より理解を問う。論題と単元の対応は名称による

論題 35 のうち、単元が受け持つもの 35、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
