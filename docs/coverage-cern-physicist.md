# 網羅表：CERN の素粒子物理学者

この頁は `tools/roadmap.py build` が `coverage-cern-physicist.yaml` から作ります。手で直さないでください。

論題 20 のうち、単元が受け持つもの 20、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
