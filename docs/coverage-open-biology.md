# 網羅表：生物学の大きな未解決問題（生命の起源、真核細胞の誕生、再生など）

この頁は `tools/roadmap.py build` が `coverage-open-biology.yaml` から作ります。手で直さないでください。
生物学の大きな未解決問題（生命の起源、真核細胞の誕生、再生など）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：Science 誌の特集 "What Don't We Know?"（2005）の生命科学の問い（生命の起源、器官の再生、細胞の運命、人に固有の遺伝的変化）。進展は Nature の論文とノーベル賞の公式の発表で確かめた（2026-11-08）。

論題 6 のうち、単元が受け持つもの 6、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
