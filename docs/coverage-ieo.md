# 網羅表：国際経済オリンピック（IEO）

この頁は `tools/roadmap.py build` が `coverage-ieo.yaml` から作ります。手で直さないでください。
国際経済オリンピック（IEO）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IEO の Syllabus（2025-12-31 に国際理事会が承認）の 2.3 経済学の論題と 2.4 金融の論題、3.6 ビジネスケースに要る力による（2026-11-08 取得）。推薦の教科書は CORE Econ の The Economy 2.0（ミクロとマクロ）と Mankiw の Principles of Economics。論題はプラットフォーム市場、デジタル決済、AI と生産性、気候の移行など今の場面に当てはめて出す。論題と単元の対応は名称による

論題 24 のうち、単元が受け持つもの 24、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
