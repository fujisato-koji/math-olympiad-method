# 網羅表：NCF-Envirothon（国際大会）

この頁は `tools/roadmap.py build` が `coverage-envirothon.yaml` から作ります。手で直さないでください。
NCF-Envirothon（国際大会）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：National Conservation Foundation Envirothon の 4 分野（Aquatic Ecology、Forestry、Soils and Land Use、Wildlife）と Current Environmental Issue の Learning Objectives（2021-02-24 承認）と、大会の頁による（2026-11-08 取得）。目標は国際大会の水準で、全部の項目が毎年出るわけではなく、毎年の資料（5 月ごろ）で主題を示す。国や州に固有の法律と機関、人物の項目は論題にしない。論題は分野の主な見出しごとに細目をまとめて立てた。論題と単元の対応は名称による

論題 20 のうち、単元が受け持つもの 19、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
