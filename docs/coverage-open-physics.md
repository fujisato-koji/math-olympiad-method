# 網羅表：物理学の大きな未解決問題（統一理論、暗黒物質、物質と反物質など）

この頁は `tools/roadmap.py build` が `coverage-open-physics.yaml` から作ります。手で直さないでください。
物理学の大きな未解決問題（統一理論、暗黒物質、物質と反物質など）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：米国の素粒子物理の計画 P5（2023、6 つの科学の駆動要因）、欧州素粒子物理戦略 2020 の Physics Briefing Book（強い CP 問題と階層性問題）、Science 誌の特集 "What Don't We Know?"（2005）の物理の問い。2026 年の状況は各実験の論文と公式発表で確かめた（2026-11-08）。

論題 8 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
