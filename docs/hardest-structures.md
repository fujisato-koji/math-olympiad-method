# 難問の構造（最難関を作るための調査）

最難関（決勝級）を、思いつきの型でなく、世の中の難問の構造から作るための調査（2026-11-11）。易しい定番の型に寄った候補が評価役の採点で落ちたこと（docs/hardest-review.md）を受けて行った。

## 調べ方

- **分類の物差し**：Engel, *Problem-Solving Strategies*（Springer, 1998）の章立てと、Zeitz, *The Art and Craft of Problem Solving*（Wiley, 第 3 版, 2017）の strategy と tactic を土台に、日本の大会（算数オリンピック、ジュニア算数オリンピック、灘中入試、JJMO、JMO）の型を足して、27 の構造（S01〜S27）に分けた。調べたあとで、収まらない構造を 6 つ足した（S28〜S33）。
- **材料**：リポジトリに記録した過去問 1,341 件（problems/*.yaml）。そのうち 1,281 件は要（key）を、古典 60 件は本文を読んで、主の構造を 1 つ、必要なら副を 1 つ付けた（係が印を付け、全件の表は作業用の控えに置いた）。問題文は写していない（R-22）。
- **水準**：E＝算数オリンピック・灘中（19 件）、J＝ジュニア数学オリンピック（145 件）、M＝日本数学オリンピック（190 件）、X＝IMO・IMO 予選問題集・USAMO・APMO・EGMO（927 件）、C＝古典（60 件）。**E は 19 件しかないので、割合はあてにならない。**

## 分かったこと

1. **小学生・中学生の大会（E、J）で多いのは、角と円、素因数、相似と比、上限と下限、偶奇と余り、場合分け。** これらは受験と大会の対策の本で型として出回っており、強い子は知っている。最難関にしても、型を知っているかどうかの問題になりやすい（評価役が落とした 3 問は、この形だった）。
2. **上の大会（M、X）では多いのに、E と J にほとんど出ない構造がある。** 副も含めた割合（E＋J の 164 件と、M＋X の 1,117 件）で比べると、次の差が大きい。
   - S14 小さい場合から・帰納法（1.2% と 8.3%）
   - S20 不等式の技（1.8% と 7.9%）
   - S05 二重に数える（1.8% と 4.5%）
   - S01 不変量（2.4% と 4.5%）
   - S07 極端なものを考える（4.9% と 7.3%）
   - S21 関数方程式（0% と 7.1%）
   - S12 構成（J では主にならない）
   - S28 離散の中間値、S31 調整法、S32 周期性、S29 グラフへの言いかえ
3. **最難関の狙い目は 2.** 小学生の道具（数、表、図、場合分け）だけで解けるのに、受験の型としては出回っていない。その場で構造を見つける段が自然に入る。

## 最難関の作り方

1. 構造を 1 つ選び、その単元の道具（と uses）で表せる設定を考える。
   - S14：表を書いて規則を見つけ、一般の場合に示す。
   - S20：周の長さが同じなら、どの形の面積が最大か。
   - S05：同じ量を 2 通りに数えて、条件を満たす配置があるかを決める。
   - S21：決まりから表を埋め、ほかの値をすべて決める。
   - S28：1 ずつしか変わらない量で、ある値になる時が必ずあることを示す。
   - S31：入れかえると良くなることを示し、いちばん良い並びを決める。
   - S32：くり返しを見つけて、遠い番号の値を出す。
   - E と J に多い構造（S24 角と円、S11 素因数、S23 相似と比、S10 上限と下限、S09 偶奇と余り、S15 場合分け、S03 対称）は、型を 1 つ当てはめて終わらないように、2 つ目・3 つ目の工夫（補助線と比の連鎖、余りと上限の組み合わせ、場合分けの設計そのもの）を入れる。
2. 小さな場合を計算機で全部調べ、すぐには見えない規則があるものを選ぶ。探した道具を、そのまま check（全部の場合の数え上げ）にする。答えが予想で当たる形なら、問いを変えるか、わけを書かせる。
3. 大会の問題と同じ問いなら、問いを変える（R-22）。海外の既出は note に書く。
4. 物差し（docs/hardest-rubric.md）の 6 つの条件で、作った係とは別の評価役が採点し、合格したものだけを最難関にする。採点の記録は docs/hardest-review.md に残す。

## 網羅の方針（D-102）

施主「角と円、素因数、相似と比、偶奇と余り、場合分けなども必要なので、知ってるかどうかになるとしても網羅的にやってください」（2026-11-11）。

- 最難関は、E と J に少ない構造だけでなく、**S01〜S33 の全部の構造**で作る。受験で定番の構造（角と円、素因数、相似と比、偶奇と余り、場合分けなど）も入れる。
- 定番の構造を使う問題は、型を知っている子に有利でも、それだけでは落とさない。落とすのは、型を 1 つ当てはめれば終わり、工夫が 3 段にならないもの（物差しの条件 1）。
- 第 1 期の 40 問は、どの構造にも 1 問以上（33 問）と、E と J に多い構造に 7 問（S24 に 2 問、S23・S11・S09・S10・S15 に 1 問ずつ）。最終の 200 問は、過去問の構造の件数の割合に近づける。
- 前からある最難関 6 問（A-015、A-017、G-012、G-019、L-010、N-017）は、同じ物差しで採点しなおし、6 問とも不合格で総動員に移した（docs/hardest-review.md）。同じ構造の決勝級を作りなおす。
