この頁は `tools/roadmap.py build` が `coverage-neuralink-bci-engineer.yaml` から作ります。手で直さないでください。
脳とコンピュータをつなぐエンジニア（Neuralink）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：Neuralink の 2 件の募集による（Greenhouse の求人システムの公開データ、2026-11-08 取得）。Neuroengineer, Next Gen（次世代の脳–コンピュータ・インターフェース。電気刺激の計算モデルと符号化の戦略、神経の記録と刺激の実験、視覚の人工器官）と Machine Learning Engineer（運動野の 1,024 電極からの解読、腕と手の 29 の自由度の解読、皮質内の信号からの声の合成）。学位は神経科学・生物医学工学・電気工学・機械学習（Neuroengineer）、計算機科学などの学士以上（機械学習の職。神経科学の経験は要らないと書く）。論題は職務と資格と望ましい経験の項目から立てた。論題と単元の対応は名称による
