# 問題を書く係の要点 1 枚（D-138 の試し、D-200 で図の部品と確かめのまとめを足した）

docs/problem-figures.md の決まりを、書く係・直す係が要る分だけに絞ったもの。迷ったときだけ元の文書を引く。施主の願い：**見ただけでわかるように。見本とヒントは、できるだけ図とイラストで。**

## 書き方（トークンを使いすぎない）
- 単元は日ごとの小さなファイルに書く。置き場は OS の一時フォルダの `michisuji-work/math-olympiad-method/<記号>/`（`python tools/assemble.py --dir <記号>` で場所が出る）。
  - `head.yaml`：頭注の行（`# <記号> <題>`、`#`、`# 段 n・水準 n・n 日。扱うこと。` など）と `id: <記号>`。
  - `day-1.yaml`、`day-2.yaml` …：単元のファイルの `days:` の下にそのまま入る形（1 行目は `  - day: 1`、字下げは単元のファイルと同じ）。
  - `ri.yaml`：`ri:` の下にそのまま入る形（1 行目は `  - part: 離`）。
- 書いたら `python tools/assemble.py <記号>` で `units/<記号>.yaml` を組み立てる。直すときも日のファイルを直し、組み立て直す（単元のファイルを直に直さない。組み立てで上書きされる）。
- 1 日分は 1 回の Write で書く。何度も読み直さない。画像は見ない（図は下の確かめで測る）。
- 図は svg を手で書かず、**`fig:` の 1 行で部品を呼ぶ**（下の「図」）。
- 確かめは 1 回で：`PYTHONIOENCODING=utf-8 python tools/selfcheck.py <記号>`（Bash の timeout は 600000）。組み立て、決まりと漢字（unitqc：誤り 0、漢字 0）、図の測り（figlint：重なり・はみ出し・小さい字 0）、ヒントの点検（hintlint：答えの漏れ・選択肢の消しすぎの疑い。出たものは 1 つずつ見て、直すかそのままかを決める）をまとめて出す。

## 日の並びと数
- 日数 n で決まる：4＝導入・練習・わけ・確認、5＝導入・練習・わけ・混ぜる・確認、6＝導入・練習・練習・わけ・混ぜる・確認、7＝導入・練習・練習・練習・わけ・混ぜる・確認。題のかっこの中を日に割り振り、後ろの日の中身を先取りしない。
- 導入・練習の日：見本 1（その日の新しいことを絵 1 枚で）、今日 4〜6、挑戦 1、2 日目からは思い出す 1〜2。わけの日：part: わけ 1（explain、ヒント 3 段、paths 2 本）。混ぜる・確認の日：今日 5〜6。どの日にも extra（予備）2。

## 問題の形
```yaml
  - day: 1
    items:
      - part: 見本
        text: 子に見せる説明（短い文 2〜4 行）
        fig: atom('Na', label='ナトリウム')
        explain: 保護者向けの、なぜそうなるか
      - part: 今日
        text: 問い（短く。絵が中身を語る）
        fig: [atom(11, cx=80, r=60), atom(17, cx=240, r=60)]
        choices: [ア, イ, ウ]
        answer: イ
        check: "'イ'"
        hints:
          - 見るところを言う文（「1 段目」などの札は書かない。画面が順に出す）
          - text: 手がかり（答えの手前まで絵で）
            fig: [atom(11, cx=80, r=60, val='赤'), ring(80, 40, 18)]
          - もう一歩（答えは書かない）
        paths:
          - [1 本目の考えの段, 段, 答えに着く段]
          - [2 本目（別の見方）, 段]
    extra:
      - （予備 2 つ。今日と同じ形）
```
- part は 見本・思い出す・今日・挑戦・わけ・離。見本とわけは explain が要る。ほかは answer とヒント 3 段。挑戦とわけと離は paths 2 本。
- 数の答えの check は問題の数から計算する 1 行の Python 式（math、itertools、Fraction、min max len sorted sum range abs all any set divmod pow）。選ぶ問題は `"'イ'"` でよい。小数は引用符で `"4.0"`。10 の何乗は `2 × 10⁻⁷`。
- 選択肢の並びは画面が混ぜる（D-134）。位置で言わない（「1 つ目」「左の ボタン」）。答えは 1 つに決める。
- YAML：`? | > - * & ! % @ \`` で始まる文字列や `: `、` #` を含む文字列は引用符でかこむ。`fig:` の行は組み立てで svg に置きかわるので、かこまなくてよい（式は 1 行）。

## 子に見せる文と字
- 段の学年までの漢字だけ（段 1＝小 1 … 段 4＝小 4、段 5＝小 5、段 6＝小 6。段 7 から上は字の決まりなし。tools/kanji-grades.json）。理科のことばも、段の字にないものはかな。用語（その単元で教えることば）は《用語》（glossary.yaml にあるものだけ）か、見本の text で先に言う。頭注だけで通る字も、ふつうのことばならかなに開く。
- 段 1〜2 は文節ごとに半角の空白で区切る。**段 3 以上は区切らない**（ふつうの文。段の字で書ける語は漢字で書き、かなに開きすぎない）。数・記号・英字の前後は、どの段も半角の空白。
- selfcheck の「頭注だけで通っている字」「用語集の字だけで通っている字」（用語集の語の外で、その語の字を使っている。例：《物質波》の質を「物質」に）は 1 つずつ見る。その単元で教える語なら頭注に書いて残し、ほかはかなに開く（D-135、D-200）。

## 図
- **部品を呼ぶ**：`PYTHONIOENCODING=utf-8 python tools/figparts/catalog.py <分野>`（化学は chem）で部品の一覧を 1 回だけ読む（部品のファイルの中身は読まない）。`fig:` に 1 行の python の式を書くと、組み立てのとき svg になる。並び `[a, b, …]` を返せば 1 枚に包む。位置は 320×200 の中の座標（cx, cy は中心）。
- 形のこまかい絵は、土台の部品（line、circle、rect、path、poly、text、arrow、ring、table、bars、plot）を並べて描く。それでも描けないものだけ `svg:` を手で書く。
- 単元の中で何度も使う絵で部品がないものは、置き場の `parts.py` に関数を書く（土台の部品は import なしで使える。`def flask(cx, cy): return circle(...) + ...`）。分野の部品のファイル（tools/figparts/*.py）は書きかえない。
- ヒントで見るところは `ring`（点線の輪）や `box_mark`、答えの場所を伏せるのは `qmark`、周期表のますは `q={'Mg': '？'}`。
- 見本には必ず図。今日・挑戦も、できるだけ絵を見て答える形。ヒント 3 段のうち 1〜2 段は図（{text, svg}）にし、答えの手前まで見せる（正解そのものは描かない）。
- `viewBox="0 0 320 200"` を基本、width・height は書かない。単純な形（circle、ellipse、rect の rx、path、line、polygon）。1 枚に 1〜3 つ。大事なものは viewBox の半分ほどの大きさ。
- 線 `stroke="currentColor"` 太さ 2、文字 `fill="currentColor"` font-size 13〜16。ぬりは淡い色 `fill-opacity` .35〜.7：黄 #f3c969、空色 #7fc8f8、緑 #7bc96f、赤 #f08080、茶 #c9a36b、紫 #b39ddb、灰 #c8ccd6。
- 使えない：script、foreignObject、on…=、href、url(…)、外の画像、marker（矢印は polygon）。天びんも svg で描く。
- 同じ物は単元の中で同じ描き方にする（同じ部品を同じ大きさで呼ぶ）。

## 審査で多かった指摘（書く前と書いたあとに見る）
- ヒントが答えをほぼ言う（正解だけに当てはまる言い方）。ヒントで選択肢を消すのは 3 段で 1 つまで、2 択では消さない。
- 問いと絵が合わない（答えの手がかりが絵か文にない）／絵を見ただけで答えが出る。
- 数える問題なのに文に数が書いてある。
- 子の文で説明していない用語を使う。
- 絵や記号の約束（💯 は 100、🔵 は 1 など）は、見本だけでなく、その問題の文か図の中で言う。腕試し・確かめ・おさらいは見本なしで出る（D-192。N-009 の腕試しで「💯 が 4 こ…」の意味が取れなかった）。
- 時がたつと答えが変わる言い方（「この あと」）。
- 同じ単元の中で、同じ問題（文・図・選択肢・答えが同じ）をくり返さない。思い出す・混ぜる・確認の日も、数や場面を変えた新しい問題にする（子が答えを覚えて解けてしまう。D-191。unitqc.py が誤りとして出す）。
- 図の字や数が、そのまま答えになる（原子の核の「+14」を読むだけで 14 族、など）。
- ヒントの点線の行や列で、選択肢がいっぺんに 2 つ以上消える。
- 段 3 以上なのに文節ごとの空白で書く（D-200 の試しで 3 単元とも。段の決まりを先に見る）。
