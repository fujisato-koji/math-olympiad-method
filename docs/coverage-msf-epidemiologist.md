# 網羅表：国境なき医師団（MSF）の疫学者

この頁は `tools/roadmap.py build` が `coverage-msf-epidemiologist.yaml` から作ります。手で直さないでください。
国境なき医師団（MSF）の疫学者に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：MSF の職の紹介「Epidemiologist」（msf.org、2026-11-08 取得）の仕事と要件による。米国の支部の同じ頁は 403 で取れなかった。WHO の疫学者は、一次資料の募集の頁（careers.who.int の個々の募集）を見つけられず、使っていない。論題と単元の対応は名称による

論題 6 のうち、単元が受け持つもの 6、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
