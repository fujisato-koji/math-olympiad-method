# 網羅表：半導体の製造工程の技術者（TSMC の工程の統合と工程モジュール）

この頁は `tools/roadmap.py build` が `coverage-tsmc-process-engineer.yaml` から作ります。手で直さないでください。
半導体の製造工程の技術者（TSMC の工程の統合と工程モジュール）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：TSMC の公開の採用サイト（ro.careers.tsmc.com）の 3 件の募集による（2026-11-08 取得）。TSMC Arizona の Process Integration Engineer（第 1 工場は N4、第 2 工場は N3 と N2、第 3 工場は 2 nm かそれより進んだ工程）と Module Process Engineer（CMP、CVD、PVD、エピタキシ、拡散、ウェット洗浄、計測、エッチング、リソグラフィの各モジュール）、TSMC Technology の Corporate Research の R&D Principal Engineer for Novel Materials and Integration Solutions（新しい材料と 3 次元の構造と熱の管理）。careers.tsmc.com の募集の頁は Cloudflare の確かめで機械では読めなかったので使わなかった。学位は電気工学・材料科学・物理・化学工学・機械工学（研究開発の職は物理・材料科学・化学・電気工学の博士）で、モジュールの職は数値解析・統計・光学・化学・物理の学力を挙げる。論題は職務と資格の項目から立てた。論題と単元の対応は名称による

論題 16 のうち、単元が受け持つもの 16、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
