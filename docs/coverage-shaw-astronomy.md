# 網羅表：天文学者（ショウ賞の天文学部門の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-shaw-astronomy.yaml` から作ります。手で直さないでください。
天文学者（ショウ賞の天文学部門の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：2004〜2026 年のショウ賞の天文学部門の授賞の理由（23 回）と、大学院の入口としてカリフォルニア大学サンディエゴ校の天文学・天体物理学の博士課程の必修科目（Core A の放射過程と天体流体力学、Core B の惑星と系外惑星、星の構造と進化、星間物質、銀河と銀河力学、宇宙論、星の残骸から 3 科目）による（2026-11-07 取得）。カブリ賞の天体物理学部門は使っていない。論題と単元の対応は名称による

論題 20 のうち、単元が受け持つもの 20、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
