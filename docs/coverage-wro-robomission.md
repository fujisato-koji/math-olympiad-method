# 網羅表：World Robot Olympiad（RoboMission）

この頁は `tools/roadmap.py build` が `coverage-wro-robomission.yaml` から作ります。手で直さないでください。
World Robot Olympiad（RoboMission）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：WRO Association の 2026 RoboMission General Rules（焦点の領域と、年齢帯ごとに難しくなる点）と、カテゴリーの頁（年齢帯 Elementary 8〜12、Junior 11〜15、Senior 14〜19）による（2026-11-08 取得）。課題（Game Rules）は毎年変わり、大会の日に驚きのルールと追加の課題が出る。カメラは Junior と Senior だけ使える。論題は焦点の領域と難しさの段階から立てた。論題と単元の対応は名称による

論題 8 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
