# 網羅表：国際物理オリンピック（IPhO）Syllabus

この頁は `tools/roadmap.py build` が `coverage-ipho.yaml` から作ります。手で直さないでください。
国際物理オリンピック（IPhO）Syllabusに要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：IPhO 公式サイトの Statutes and Syllabus による（2026-11-07 取得、シラバスの版の表示なし）。論題と単元の対応は名称による。シラバス外の概念は問題文で説明すれば出してよい。数学は「中等学校の生徒が標準的な高校の数学で解けること」が条件

論題 8 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
