# 網羅表：European Girls' Mathematical Olympiad（EGMO）

この頁は `tools/roadmap.py build` が `coverage-egmo.yaml` から作ります。手で直さないでください。
European Girls' Mathematical Olympiad（EGMO）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：公式の範囲の文書はない。General Regulations（IN008）は 4.2 で問題を「大学より前の数学のいろいろな分野」とだけ書く。そこで過去問 92 問（2012〜2026）の型付けの記録（IN012）を単元ごとに集計し、2 問以上に出た論題を IMO の網羅表（coverage.yaml）の立て方でまとめた。論題の括弧の数はその論題の単元を使う問題の数。1 問だけの論題（ゼッケンドルフ表示、周期の補題、ハミング距離、ロルの定理など）は入れていない

論題 35 のうち、単元が受け持つもの 34、すべての単元に通る軸が受け持つもの 1、入れないもの 0。
