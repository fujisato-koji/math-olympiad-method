# 網羅表：統計学者（国際統計学賞の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-stat-prize.yaml` から作ります。手で直さないでください。
統計学者（国際統計学賞の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：2017〜2025 年の国際統計学賞の授賞の理由（2 年ごと 5 回）と、大学院の入口としてスタンフォード大学統計学科の博士課程の資格試験（応用統計、確率論、理論統計の 3 科目）と、カリフォルニア大学バークレー校の Stat 210A（博士課程の入門の理論統計、2025 年秋の講義の一覧）による（2026-11-07 取得）。スタンフォードの資格試験の細目は学内限定のため科目名だけを使った。論題と単元の対応は名称による

論題 15 のうち、単元が受け持つもの 14、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
