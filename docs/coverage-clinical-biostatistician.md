# 網羅表：臨床試験の生物統計家（FDA、MSD、GSK）

この頁は `tools/roadmap.py build` が `coverage-clinical-biostatistician.yaml` から作ります。手で直さないでください。
臨床試験の生物統計家（FDA、MSD、GSK）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：FDA の Center for Veterinary Medicine の Mathematical Statistician（FDA-CVM-26-T21-1305257-ATG、2026-07-21〜27、締切済み）、MSD の Principal Scientist, Biostatistics, Late-Stage Clinical Development（R414604、2026-10-27 掲載）、GSK の Associate Director – Oncology Statistics（450338、2026-10-27 掲載、2026-11-10 締切）の募集と、募集が求める「統計の方法と実験計画」「世界の規制の要件」の範囲として ICH E9（1998）と E9(R1)（2019）の章立てによる（2026-11-08 取得）。MSD と GSK は Workday の採用の頁が読む公開の求人データから読んだ。FDA の募集は知識の分野を名指ししないので、学位と仕事を論題にした。2026 年の FDA の生物統計の部門の募集は管理職（CBER の Office Director、CDRH の Director）しか見つからず使っていない。論題と単元の対応は名称と募集の本文による

論題 23 のうち、単元が受け持つもの 23、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
