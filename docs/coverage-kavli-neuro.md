# 網羅表：神経科学の研究者（カブリ賞・神経科学の研究に届く知識）

この頁は `tools/roadmap.py build` が `coverage-kavli-neuro.yaml` から作ります。手で直さないでください。
神経科学の研究者（カブリ賞・神経科学の研究に届く知識）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：カブリ賞・神経科学の 2008〜2026 年の全 10 回の受賞理由（kavliprize.org）と、大学院の入口として神経科学の博士課程の必修（Stanford、UC San Diego、Harvard）と Society for Neuroscience の大学院の訓練の中核の能力による（2026-11-07 取得）。博士課程の文書は領域の名前までで、細目はない。論題と単元の対応は名称による

論題 21 のうち、単元が受け持つもの 21、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
