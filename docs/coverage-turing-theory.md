# 網羅表：理論計算機科学者（ACM チューリング賞）

この頁は `tools/roadmap.py build` が `coverage-turing-theory.yaml` から作ります。手で直さないでください。
計算と情報のしくみを数学の言葉で調べ、暗号や学習するプログラムなど、新しい計算のやり方の土台をつくる。に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

論題 9 のうち、単元が受け持つもの 8、すべての単元に通る軸が受け持つもの 0、入れないもの 1。
