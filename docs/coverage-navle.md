# 網羅表：北米の獣医師国家試験（NAVLE）

この頁は `tools/roadmap.py build` が `coverage-navle.yaml` から作ります。手で直さないでください。
北米の獣医師国家試験（NAVLE）に要る論題ごとに、受け持つ単元か、入れない理由を書いています（R-09）。

範囲の根拠：ICVA の NAVLE の出題の設計（exam blueprint の頁の能力の領域と動物種の配分）と、能力の領域の文書（NAVLE Competency Domains）、2017 年の業務の分析の要旨による（2026-11-08 取得）。今の出題の設計は 2017 年の分析にもとづく。能力の領域は臨床 70%、予防医学と動物の福祉 15%、意思疎通 8%、職業と経営と健康 7%。動物種は犬 25.6%、猫 24.3%、馬 14.7%、牛 13.3%、豚 5% ほか。意思疎通と職業は beyond に書いた。論題と単元の対応は名称による

論題 16 のうち、単元が受け持つもの 16、すべての単元に通る軸が受け持つもの 0、入れないもの 0。
